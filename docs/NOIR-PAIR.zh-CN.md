# 暗黑漫画：撕页斩与缝影绞索

两款独立 pixelfx 特效，依据用户选定的概念制作。煤黑主体、冷灰分面和少量旧纸白亮边保持轮廓，裂口与缝线使用暗红；动画均包含清楚的准备、释放、停顿和收尾。

在画廊搜索 **暗黑漫画** 可同时找到两款；也支持分别搜索中文名或英文 ID。

| 名称 | ID / 分类 | 画布 | 锚点 | 时长 / 帧数 |
| --- | --- | --- | --- | --- |
| 撕页斩 | `melee/noir-page-rend` / 近战 | 448 × 384 | (224, 326) | 3.25 秒 / 79 帧 |
| 缝影绞索 | `shadow/noir-shadow-stitch` / 暗影 | 448 × 336 | (224, 226) | 4.5 秒 / 109 帧 |

两款均为 24 FPS、单次播放，起始与结束帧完全透明。锚点为效果的地面参考点；撕页裂口主体位于锚点上方，缝影的人形阴影铺在锚点周围的地面透视平面上。

## 动作

### 撕页斩

- 0.08–0.375 秒：细长旧纸白划痕沿斜线展开，停留至约 0.71 秒。
- 0.71–0.89 秒：裂口迅速张开，厚纸两侧翻起，露出暗红内缘与墨黑深处。
- 0.89–1.67 秒：卷边轻微回弹，粗糙纸面保持硬边分色；两处较大的翻卷和成组排线表现纸张厚度。少量黑纸屑向外飞出后减速翻落。
- 1.67–1.875 秒：纸边快速闭合，留下一条短暂红痕。
- 1.875–3.25 秒：第二批纸屑缓慢翻落、淡出，最终清空。

导出的 `cues` 包含 `scratch / release / impact / closing / shut`。`palette` 控制纸边与纸屑；`rift` 控制裂口的暗红色阶。

### 缝影绞索

- 0.25、0.458、0.667、0.875 秒：四枚带穿线孔的黑铁钉依次落地，伴有轻微震动、细碎裂纹与煤屑。
- 1.00–1.87 秒：四股红线从钉眼伸出，针尖沿人形阴影边缘移动，留下独立横针脚和细引线。
- 1.917–2.125 秒：引线由松弛转为绷紧，影子四肢被拉长，躯干收窄并显出尖锐褶皱。
- 2.125–2.958 秒：保持束缚，绷紧的引线带轻微颤动。
- 2.958、3.125、3.292、3.458 秒：四股线依次断开；钉眼一端回弹后垂落，影子一端松弛消散。
- 3.72–4.5 秒：影子收拢、铁钉沉下，线头与阴影淡出。

导出的 `cues` 包含四个 `pins` 时刻，以及 `sewing / tighten / bound / release / breaks`。`palette` 控制黑铁与阴影；`thread` 控制红线。

缝影内的人形是风格化的独立影子，不自动读取宿主角色的轮廓。接入游戏时可把自己的角色画在影子上方；两款动画均不包含伤害、位移或束缚判定，也未接入 Godot 战斗系统。

## 预览与导出

在 pixelfx 目录运行：

```powershell
node tools/serve.mjs 8080
node tools/render.mjs melee/noir-page-rend shadow/noir-shadow-stitch --gif --mp4 --sheet --scale 1 --zoom 1
```

画廊地址为 `http://localhost:8080/gallery/`，支持重播、暂停、慢放、背景、配色、随机种子、镜像和图集生成。

导出目录分别为 `records/melee/noir-page-rend/` 与 `records/shadow/noir-shadow-stitch/`，各含：

- `anim.gif`、`anim.mp4`：动态预览。
- 同名 `.png` 与 `.json`：透明 RGBA 图集与 Aseprite 兼容帧数据。
- `contact.png`：关键帧总览。

图集导入使用最近邻采样，按 JSON 的 `meta.pixelfx.pivot` 设置原点。两款代码支持 `x / y / flip / angle / seed / light`；主色和专属色阶均支持短数组换色，`stop()` 使用公共运行时的 0.3 秒淡出。
